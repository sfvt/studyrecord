# 学習記録アプリ PC画面レイアウト案

全体の完成像に対するワイヤーフレームです。配置・サイズ・文言の案であり、実装済み・採用確定ではありません。2週間版の範囲は後で切り分けます。
色や装飾より、情報と操作の配置を決めることを目的とします。

## 共通レイアウト

PCでは左側にナビゲーション、右側に画面の内容を置く案です。本文は最大幅を設け、横に広がりすぎないようにします。
計測画面から直接入力する既存の分野選択欄は設けず、分野は終了後のモーダルで選択します。

```text
┌──────────────────────────────────────────────────────────┐
│ 学習記録アプリ                  study_user  ［ログアウト］│
├────────────┬─────────────────────────────────────────────┤
│ 計測       │ ページの見出し                              │
│ 振り返り   │                                             │
│ 分野管理   │ ページの内容                                │
│            │                                             │
└────────────┴─────────────────────────────────────────────┘
```

現在地を強調表示します。ログイン画面にはこのナビゲーションを表示しません。
計測中は他の画面にも「計測中 00:42:10 ［計測画面へ］」を表示する案です。画面遷移で計測を継続する全体仕様に対応します。

## 1. ログイン画面

```text
                  学習記録アプリ
           ┌────────────────────────┐
           │ ログイン               │
           │                        │
           │ ユーザー名             │
           │ ［                    ］│
           │ パスワード             │
           │ ［                    ］│
           │                        │
           │ ログインエラーの表示   │
           │ ［     ログイン      ］│
           └────────────────────────┘
```

- エラーはフォーム内に表示し、パスワードは再表示しません。
- 最初は新規登録・パスワード再設定・Remember-meの入口を置きません。

## 2. 計測画面

```text
┌─────────────────────────────────────────────────┐
│ 学習時間を計測                                  │
│                                                 │
│                  ╭────────────╮                 │
│                  │  00:00:00  │                 │
│                  ╰────────────╯                 │
│                                                 │
│                 ［ 計測を開始 ］                │
│                                                 │
│ 分野とメモは、計測終了後に入力できます。         │
│                                                 │
│ ［計測せずに記録する］                          │
└─────────────────────────────────────────────────┘
```

- 計測開始後は同じ位置のボタンを「計測を終了」に切り替える案です。
- 一時停止・モード切り替えは置きません。
- 「計測せずに記録する」は手動追加用の記録入力モーダルを開く追加の配置案です。計測中は使えない状態にし、計測中の別記録入力を増やさない案とします。
- 終了時は時間を確定し、同じ画面上に記録入力モーダルを開きます。

## 3. 記録入力モーダル

```text
┌──────────────────────────────────────────────────────────────┐
│ 学習記録を入力                                               │
│ 学習日 ［2026-10-18］           計測時間：2時間00分            │
│                                                              │
│ 分野             学習時間           メモ                操作 │
│ ［JavaScript ▼］ ［1］時間［0］分   ［配列操作         ］［削除］│
│ ［CSS        ▼］ ［0］時間［30］分  ［レイアウト       ］［削除］│
│                 項目ごとの入力エラー                         │
│                                                              │
│ ［＋ 入力行を追加］                                           │
│                                                              │
│ 合計学習時間：1時間30分                                       │
│ 計測時間は120分、入力合計は90分です。このまま保存できます。   │
│ 保存エラーの表示                                             │
│                                                              │
│ ［破棄する］                                ［記録する］     │
└──────────────────────────────────────────────────────────────┘
```

- 背景は暗くし、背後の画面は操作できない状態にします。「×」や「閉じる」は置きません。
- 日付・各行の分野・時間・メモを直接入力します。同じ分野を複数行で選べます。
- 「＋ 入力行を追加」で空の行を追加し、各行の「削除」でその入力行を取り除く配置案です。DBには記録・更新成功時だけ反映します。
- メモは任意です。項目エラーは該当欄の近く、保存全体の失敗は下部に表示します。注意文と保存不可のエラーを区別します。
- 合計時間は自動計算して表示し、入力欄にはしません。
- 行が増えたら入力部分を縦スクロールさせ、下部の合計・ボタンを見失わない配置にする案です。
- 記録処理中は確定ボタンを無効にし、処理中であることを表示します。
- 手動追加では計測時間と差の注意文を表示しません。学習日の初期値は決定済みの「今日」とします。
- 編集時は見出しを「学習記録を編集」、ボタンを「変更を破棄する」「更新する」に変えます。
- 破棄確認はブラウザー標準の確認ダイアログなど、簡単な方法から実装できます。

```text

│ 学習の振り返り                                        │
│                                                       │
│ ┌───────────────────────────────────────────────────┐ │
│ │ トータル学習時間          128時間30分               │ │
│ └───────────────────────────────────────────────────┘ │
│                                                       │
│ 分野別学習時間                                        │
│ JavaScript                              80時間00分    │
│ CSS                                     48時間30分    │
│                                                       │
│ 学習カレンダー             ［前月］2026年10月［翌月］ │
│ ┌──────┬──────┬──────┬──────┬──────┬──────┬──────┐       │
│ │ 日   │ 月   │ 火   │ 水   │ 木   │ 金   │ 土   │       │
│ ├──────┼──────┼──────┼──────┼──────┼──────┼──────┤       │
│ │ …    │ …    │ …    │ …    │ …    │ …    │17    │       │
│ │      │      │      │      │      │      │1時間 │       │
│ │      │      │      │      │      │      │30分  │       │
│ ├──────┼──────┼──────┼──────┼──────┼──────┼──────┤       │
│ │18    │ …    │ …    │ …    │ …    │ …    │ …    │       │
│ │2時間 │      │      │      │      │      │      │       │
│ └──────┴──────┴──────┴──────┴──────┴──────┴──────┘       │
└───────────────────────────────────────────────────────┘
```

- 全期間の合計・分野別の数値を先に、カレンダーをその下に置きます。グラフは置きません。
- 前月・翌月のボタン、今日の日付の目印を付ける案です。
- 記録がない日の時間は空欄とし、記録の有無にかかわらず日付を押せるようにします。
- 「記録なし」と「取得失敗」は異なる表示にします。集計・カレンダーの各領域に読み込み状態とエラーを表示する案です。

## 5. 日別の記録詳細モーダル

```text
┌────────────────────────────────────────────────────────┐
│ 2026年10月18日の記録                                    │
│ 合計：1時間45分                                         │
│                                                        │
│ ┌────────────────────────────────────────────────────┐ │
│ │ 記録①　合計：1時間15分             ［編集］［削除］│ │
│ │ JavaScript　30分　配列操作                          │ │
│ │ JavaScript　45分　課題制作                          │ │
│ └────────────────────────────────────────────────────┘ │
│ ┌────────────────────────────────────────────────────┐ │
│ │ 記録②　合計：30分                  ［編集］［削除］│ │
│ │ CSS　30分　レイアウト                               │ │
│ └────────────────────────────────────────────────────┘ │
│                                                        │
│ ［記録を追加］                              ［閉じる］ │
└────────────────────────────────────────────────────────┘
```

- 1回の記録を1つの枠でまとめます。同じ分野でも明細を省略・合算せず、メモとともに表示します。
- 記録がない場合は「この日の学習記録はありません」と表示し、「記録を追加」は残します。
- 追加・編集では、この詳細モーダルを隠して共通の入力モーダルへ切り替える案です。
- 閲覧用なので「閉じる」があります。入力モーダルとは区別します。

## 6. 分野管理画面（独立画面の提案）

```text
┌───────────────────────────────────────────────────────┐
│ 分野管理                                              │
│                                                       │
│ 新しい分野                                            │
│ ［分野名を入力                           ］［追加］   │
│ 入力エラーの表示                                      │
│                                                       │
│ 登録済みの分野                                        │
│ JavaScript                      ［名前変更］［削除］  │
│ CSS                             ［名前変更］［削除］  │
│                                                       │
│ 操作結果・エラーの表示                                │
└───────────────────────────────────────────────────────┘
```

- 名前変更は対象行を入力欄と「更新」「取り消す」に切り替える案です。
- 分野の削除は確認後に実行し、使用中の場合は「学習記録で使用されているため削除できません」と表示します。
- 未登録なら、最初の分野を追加する案内を表示します。
- 記録入力モーダル内での分野の新規作成はこの案には含めていません。必要性と、入力内容を失わず追加する導線は今後確認します。

## 確認したい提案

1. 左ナビゲーションと、独立した分野管理画面を採用するか。
2. 計測画面に「計測せずに記録する」を配置するか。
3. 行の追加・削除、分野名変更を上記の操作方法にするか。
4. 記録入力中に新しい分野が必要になった場合の導線をどうするか。
